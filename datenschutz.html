Cookies können von uns (First-Party-Cookies) oder von Drittunternehmen stammen (sog. Third-Party-Cookies). Third-Party-Cookies ermöglichen die Einbindung bestimmter Dienstleistungen von Drittunternehmen innerhalb von Webseiten (z. B. Cookies zur Abwicklung von Zahlungsdienstleistungen).

15. Lokale Datenspeicherung (LocalStorage)

Für die Authentifizierung im Kunden- und Admin-Bereich speichert Supabase einen verschlüsselten Session-Token im LocalStorage Ihres Browsers. Dieser Token dient ausschließlich dazu, Sie nach dem Schließen des Tabs weiterhin als eingeloggt zu erkennen, ohne dass Sie sich erneut anmelden müssen.

Der Token enthält keine Klardaten (keine Passwörter, keine Nachrichten). Er wird automatisch gelöscht, wenn Sie sich abmelden, oder nach Ablauf der Sitzungsgültigkeitsdauer.

Position des Vertriebspartner-Buttons

Auf der Startseite kann der frei schwebende "Partner werden"-Button per Ziehen verschoben werden. Die von Ihnen gewählte Position wird ausschließlich lokal in Ihrem Browser (LocalStorage) gespeichert, damit der Button beim nächsten Besuch an der gewählten Stelle bleibt. Diese Information wird nicht an unsere Server übertragen.

Anonyme Sitzungs-ID im Bewerbungsfunnel

Beim Ausfüllen des Vertriebspartner-Fragebogens (siehe Abschnitt 10) wird in Ihrem Browser (SessionStorage) eine zufällig erzeugte, nicht personenbeziehbare Kennung erzeugt. Sie dient ausschließlich dazu, die anonymen Funnel-Statistiken einer zusammenhängenden Sitzung zuzuordnen, und wird gelöscht, sobald Sie den Tab schließen.
